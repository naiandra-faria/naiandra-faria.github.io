00 · Why this exists

This is not a moodboard.

A moodboard is a mood. This is a contract. Every value on this page was read out of the CSS that is running on the site you just came from — not chosen to look good next to the others.

That direction matters: the system did not decorate the site afterwards, the site is what the system produces. When a token changes here, the page changes there — and the repository is where the two meet.

If you are evaluating me: this is the artifact to read. It shows how I decide, what I refuse, and where I stop.
